# Excel Bike Sales Dashboard

A fully interactive Excel dashboard built to analyze global bike sales performance, track revenue trends, and segment customer demographics.

## Project Overview
This project visualizes multi-year sales data using advanced Excel analysis tools to support data-driven decision-making and business insights.

## Key Features & Steps
- **Data Preparation & Cleaning:** Standardized raw sales records, fixed data entry errors (such as state and year field misalignment), and structured clean tables.
- **Pivot Tables:** Built four core Pivot Tables to analyze:
  1. Revenue by Age Group
  2. Revenue by Year
  3. Revenue by Country
  4. Revenue by Product Category
- **Interactive Dash Board:** Designed a centralized dashboard tab featuring a styled executive header banner and custom column charts.
- **Interactive Slicers:** Connected Country and Year Slicers across all Pivot Tables via Report Connections for synchronous, real-time filtering.

## Tools Used
- Microsoft Excel (Power Query, Pivot Tables, Pivot Charts, Slicers)
- GitHub (Version Control & Portfolio Presentation)
